Build with a coding agent. Debug from the record.

Use FootPrint in an ordinary application. Your coding agent can inspect its recorded run without putting an AI model inside the application.

  1. Build

    Use named stages, tracked state and explicit decisions.

  2. Record

    Run the application with the required recorders enabled.

  3. Inspect

    Follow the wrong result back through its recorded dependencies.

  4. Verify

    Add a regression test, repair the code and record another run.

Share the relevant trace slice rather than an entire log dump. The context needed depends on the workflow and tooling; no measured token or speed saving is claimed.
